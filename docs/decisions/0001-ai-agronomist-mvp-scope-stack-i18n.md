# ADR-0001: AI Agronomist MVP — Scope, Stack, and i18n Strategy

- **Number:** 0001
- **Title:** AI Agronomist MVP — Scope, Stack, and i18n Strategy
- **Date:** 2026-08-04
- **Status:** Accepted
- **Participants:** Павло Харченко (Human Founder), Qwen (AI Council Member)

## Context
1. Дослідження Google Trends (2026-08-04): нішеві українські терміни
   («точне землеробство») мають нульовий пошуковий попит; глобальний запит
   `AI in agriculture` зростає вибухово (+550% YoY, плато у 2026).
2. Нішеві AI-терміни (`crop disease detection AI`, `agro chatbot`) ≈ 0
   глобально — ринок ранній, ніші вільні.
3. Продуктова стратегія Human Founder: охопити глобальний тренд, залишаючись
   релевантним локально → три мови інтерфейсу та AI-відповідей: en, uk, ru.
4. Доменна перевага: гібрид «детерміновані агроінженерні моделі + LLM»
   для захисту від галюцинацій ШІ.

## Decision
1. Створити **AI Agronomist MVP**: веб-застосунок генерації структурованих
   агрономічних рекомендацій (культура, регіон, попередник, цільова врожайність).
2. i18n: UI — словники en/uk/ru; AI-відповіді — параметр `language` у System Prompt.
3. Стек: TypeScript, React + Vite (client), Node.js + Express (server),
   zod (валідація env і LLM-схеми), Gemini API (structured outputs).
4. Детерміновані розрахунки (техніка/паливо/норми) — у спільному доменному
   шарі; LLM лише інтерпретує та формулює поради.
5. Out of scope для MVP: GIS/карти, автентифікація, БД, платежі.

## Consequences
- **Позитивні:** збіг із трендом +550%; i18n підвищує продуктову та
  портфельну цінність; гібридна архітектура демонструє інженерну зрілість.
- **Витрати:** три словники перекладів; промпт-інжиніринг для стабільної
  мови відповіді LLM.
- **Ризики:** галюцинації LLM → мітигація: zod-валідація, доменні
  діапазони-обмежувачі, disclaimer у UI.
